Frequently asked questions

Is OpenPaint free and open source?

Yes. OpenPaint is licensed under GPL-3.0-or-later. The source code is on GitHub.

Does OpenPaint work offline?

Editing works offline, with no account or telemetry. Downloads, initial package setup and automatic release checks in native packages need an internet connection. Flatpak opens release information in your browser only.

Does it support layers or AI tools?

Not yet. OpenPaint is a single-layer editor. Layers, editable project files, crash recovery and AI tools are planned. Automatic update installation is also not included.

Is OpenPaint made by Microsoft?

No. OpenPaint is an independent project for Linux. It is not affiliated with Microsoft.

How can I report a problem or contribute?

Open an issue on GitHub and include your Linux distribution, desktop environment and steps to reproduce the problem. For code contributions, see the contribution guide.
