# OpenPaint

**A familiar paint app for Linux and macOS.**

Sketch, paint and make quick image edits with a clean desktop interface.
Free and open source. Editing works offline—no account or telemetry.

## Make it yours

- Draw with brushes, pencil, fill, shapes, splines and mixed-font text.
- Select by rectangle, free-form outline or matching color; copy, move, crop, resize and rotate.
- Add, reorder, hide, duplicate and merge layers; save editable OpenRaster projects.
- Save As PNG, JPEG, BMP, WebP or monochrome BMP; keep editable layers in OpenRaster.
- Use pixel rulers and optional alignment guides; drag a region or choose a preset to zoom.
- Adjust drawing opacity, fill disconnected matching colors, undo/redo and right-drag to pan.
- Adjust supported glass appearance; native packages check for stable releases automatically.

## Install

Linux x86_64: choose the **Ubuntu 24.04 .deb** for app-menu integration,
**Flatpak** for other distributions, or the **portable archive**.
Apple silicon Macs: use the **DMG** on **macOS 14.4 or newer**. The build is
ad-hoc signed, without Apple notarization; see the first-launch instructions.
See the [installation guide](docs/INSTALL.md) for requirements, checksums and updates.

Crash recovery, printing, AI tools and automatic update installation are not included.
macOS uses native glass; Linux glass depends on desktop support.
